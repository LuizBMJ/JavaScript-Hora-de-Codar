# JavaScript - Hora de Codar

Repositório contendo exercícios e projetos do curso de JavaScript.

## Tópicos Abordados

### 1. Fundamentos
Conceitos básicos de JavaScript, variáveis e declaração.

### 2. Tipos de Dados
Strings, Numbers, Booleans, Arrays, Objetos, Undefined e Null.

### 3. Operadores Condicionais
Operadores de comparação, lógicos (AND, OR, NOT) e estruturas condicionais (if/else).

### 4. Estruturas de Repetição
Loops for, while, do-while e controles break/continue.

### 5. Funções e Escopo
Declaração de funções, escopo de variáveis, let e const.

### 6. Métodos Nativos
Métodos de strings, números e arrays.

### 7. Objetos
Criação e manipulação de objetos, palavra-chave this.

### 8. DOM
Seleção e manipulação de elementos HTML via JavaScript.

### 9. Eventos e Callbacks
Manipulação de eventos, setTimeout, setInterval, callbacks.

## Estrutura do Projeto

```
├── Exercicios/     # Exercícios organizados por módulo
├── Json/           # Exercícios com JSON
```

Basta abrir os arquivos `index.html` no seu navegador para executar os exercícios.
