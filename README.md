## 📌 Overview

This repository contains exercises and practical projects developed during a JavaScript course from Hora de Codar.
The project covers core JavaScript concepts including variables, data types, loops, functions, DOM manipulation, events, callbacks, and object-oriented features.
It was created as a study repository focused on improving frontend development and JavaScript programming skills through hands-on practice.

## 🛠️ Technologies

* **JavaScript** — Main programming language used throughout the exercises
* **HTML5** — Structure and markup for the projects
* **CSS3** — Styling and interface customization
* **JSON** — Data structure format used in some exercises and projects

```bash id="m2v9pk"

```

Navigate to the project folder:

```bash id="x7q3lw"
cd javascript-course-projects
```
